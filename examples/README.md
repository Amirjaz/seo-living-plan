# Examples

Two unedited outputs from the skill's test runs. The sites, people and numbers are made up; the Search Console exports behind them are in [`skills/seo-living-plan/evals/`](../skills/seo-living-plan/evals/).

| File | What it shows |
|---|---|
| [setup-bakery-plan.md](setup-bakery-plan.md) | **Setup.** A 13-week plan for a bakery in Austin, built from 8 weeks of exports and a 2-hour weekly budget. It covers the baseline, a ranking strategy with evidence for each lever, target ranges with the arithmetic shown, a page-change calendar that respects the 14-day rule, and a 3-question message for the owner. |
| [weekly-report-dental-practice.md](weekly-report-dental-practice.md) | **Week 4 of a Persian dental practice's plan.** It has a blocked reachability check reported honestly, a top-3 drop alert, a fail list where every keyword gets an action or a "skipped: rule; unblocks when …", a +28-day verdict, a refused instruction (copying a stale address from a map app), and one ready-to-forward Persian message replacing three stalled asks. |

The weekly report flags two data problems ("the week 2 and week 3 totals don't match the daily read", and the KPI definition). These were real mistakes in the first version of the test data, and the run caught them on its own. The test data has since been fixed.
