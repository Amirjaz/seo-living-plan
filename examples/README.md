# Examples

Two unedited outputs from the skill's test runs. The businesses, people and numbers are made up; the Search Console exports behind them are in [`skills/seo-living-plan/evals/`](../skills/seo-living-plan/evals/).

| File | What it shows |
|---|---|
| [setup-bakery-plan.md](setup-bakery-plan.md) | **Setup** for a bakery in Austin, TX: 8 weeks of exports become a 13-week plan, with target ranges and their arithmetic, a page-change calendar and a 3-question message for the owner. |
| [weekly-report-dental-practice.md](weekly-report-dental-practice.md) | **Week 4** for a dental practice in Leeds, UK: an honest "blocked" line, a top-3 drop alert, a fail list where every keyword gets an action or a reason, a +28-day verdict, a refused instruction to copy a stale address, and one message replacing three stalled asks. |
