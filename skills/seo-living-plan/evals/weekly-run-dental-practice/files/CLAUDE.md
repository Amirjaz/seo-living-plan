- Plan: `seo/plan-1405-aban-dey.md`. Tracker: `seo/keyword-tracker.md`. Keyword sessions: `seo/keyword-watch/`. Lessons: `seo/lessons.md`. Data: `data/<date>/` (append-only).

- The practice is a «مطب» (private practice). Never write «کلینیک».
- `approved_by_doctor:` is filled only by the human, with date and channel.
- Reports go to `reports/weekly/<date>-plan.md`.
