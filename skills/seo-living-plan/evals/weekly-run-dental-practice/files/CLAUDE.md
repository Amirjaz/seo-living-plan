# Brightside Dental — SEO workspace rules

- Plan: `seo/plan-2026-q4.md`. Tracker: `seo/keyword-tracker.md`. Keyword sessions: `seo/keyword-watch/`. Lessons: `seo/lessons.md`. Data: `data/<date>/` (append-only).
- Weekly run day: Saturday/Sunday. Autonomy: drafts + non-fact fixes. No site access from this workspace: site changes are written as ready-to-apply packages in `seo/changes/<date>-<slug>.md` for the human to apply, and logged in the Change log with the date they were packaged.
- The practice is a private dental practice. Never write "clinic" or "cosmetic clinic" — Dr. Okafor doesn't want the site to read like an anonymous cosmetic chain.
- `approved_by_dentist:` is filled only by the human, with date and channel.
- Reports go to `reports/weekly/<date>-plan.md`.
